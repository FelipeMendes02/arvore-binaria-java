🌳 Projeto Árvore Binária em Java
📚 Descrição
Este projeto foi desenvolvido em Java com o objetivo de implementar uma Árvore Binária de Busca (ABB) utilizando os conceitos de Programação Orientada a Objetos.

O sistema permite realizar diversas operações em uma árvore binária através de um menu interativo no terminal.

🚀 Funcionalidades
O programa possui as seguintes funcionalidades:

Inserir elementos na árvore
Buscar elementos
Imprimir em ordem crescente
Imprimir em ordem decrescente
Contar quantidade de nós
Somar os elementos da árvore
Mostrar maior elemento
Mostrar menor elemento
Mostrar folhas
Mostrar nós que não são folhas
Mostrar altura da árvore
Mostrar profundidade dos nós
Remover elementos da árvore

📌 Explicação das Classes
🔹 No.java
Classe responsável por representar cada nó da árvore.

Cada nó possui:

valor
referência para esquerda
referência para direita
🔹 Arvore.java
Classe responsável por toda a lógica da árvore binária.

Contém os métodos de:

inserção
busca
remoção
percursos
altura
profundidade
soma
contagem
🔹 Principal.java
Classe principal do sistema.

Responsável por:

exibir o menu
receber dados do usuário
chamar os métodos da árvore
▶️ Como Executar
📌 Requisitos
Para executar o projeto é necessário ter instalado:

Java JDK 8 ou superior
Uma IDE Java (VS Code, NetBeans, Eclipse, IntelliJ) ou terminal
💻 Executando pelo Terminal
1️⃣ Abrir a pasta do projeto
Certifique-se de que os arquivos:

Arvore.java
No.java
Principal.java
estejam na mesma pasta.

2️⃣ Compilar os arquivos
No terminal, execute:

javac *.java
3️⃣ Executar o programa
java Principal
🖥️ Executando em uma IDE
VS Code
Abra a pasta do projeto
Abra o arquivo Principal.java
Clique em Run ou Executar
NetBeans
Crie um projeto Java
Adicione os arquivos .java
Execute a classe Principal.java
Eclipse
Crie um projeto Java
Importe os arquivos .java
Clique com o botão direito em Principal.java
Selecione:
Run As > Java Application
IntelliJ IDEA
Crie um projeto Java
Adicione os arquivos
Abra Principal.java
Clique no botão ▶ ao lado do método main
✅ Resultado
O menu da árvore binária será exibido no terminal da IDE, permitindo utilizar todas as funcionalidades do sistema.
